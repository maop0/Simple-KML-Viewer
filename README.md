# 航迹图 · KML 查看器

一个无需安装依赖的浏览器版 KML 地图查看器。支持航班轨迹及包含 `Point`、`LineString` 的常见 KML 文件。

## 使用

1. 用浏览器打开 `index.html`。
2. 点击“打开 KML”，选择 `.kml` 文件；也可以把文件拖到左侧导入框。
3. 地图会自动缩放到轨迹范围。点击“适配航迹”可再次定位。

地图上的蓝色圆点代表 KML 中记录的实际位置；浅蓝虚线只连接距离不超过 2 公里的相邻记录。相邻点直线距离超过 2 公里时不绘制推测航迹，并以橙色圆环标出跨过间隔后的记录点。跨日期变更线的轨迹按较短方向显示。地图可在以航迹为中心的一个世界范围内移动，不会重复显示多个世界。

地图底图来自 OpenStreetMap，Leaflet 地图库从 unpkg 加载，因此显示地图需要网络连接。KML 文件在浏览器本地读取，不会上传。
